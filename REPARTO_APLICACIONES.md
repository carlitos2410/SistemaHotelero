# Reparto de aplicaciones

El repositorio conserva completas las aplicaciones desarrolladas por Carlos:

- `reservas`
- `usuarios`

Las demás aplicaciones contienen únicamente una estructura inicial para que cada integrante implemente y registre su aporte:

| Integrante | Aplicaciones asignadas |
| --- | --- |
| Carlos | `reservas`, `usuarios` |
| Compañero 1 | `estancias` |
| Compañero 2 | `api` |
| Compañero 3 | `habitaciones` |
| Compañero 4 | `reportes`, `hoteles` |

Cada integrante debe incluir los modelos, migraciones, servicios, formularios, vistas, rutas, pruebas, plantillas y recursos estáticos que correspondan a su aplicación.

## Reglas para colaborar

1. Actualizar el repositorio local antes de comenzar.
2. Modificar únicamente las aplicaciones asignadas y sus plantillas o recursos asociados.
3. Crear commits pequeños con mensajes en español.
4. Incluir las migraciones cuando se modifiquen modelos.
5. No subir `.env`, bases de datos, entornos virtuales, archivos temporales ni credenciales.

El sistema permanecerá incompleto hasta que las cinco aplicaciones asignadas vuelvan a integrarse.
